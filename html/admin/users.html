Falta soporte en la API

El backend actual solo permite registrar, iniciar sesión y consultar al usuario autenticado. No ofrece una ruta administrativa para listar, editar, bloquear o eliminar cuentas, así que esta página no enviará cambios que el servidor no pueda procesar.

Para habilitar esta sección hacen falta endpoints protegidos para listar usuarios y administrar su estado o permisos. Los cambios de permisos deben validarse siempre en el backend.
